# Sobre

O **Blog Tempest** é onde o time do Projeto Tempest escreve, em público, sobre
as tecnologias que usa no dia a dia e as que desenvolve.

## O que você encontra aqui

- **Backend em Python** — FastAPI async-first sobre o
  [`tempest-fastapi-sdk`](https://pypi.org/project/tempest-fastapi-sdk/),
  nosso framework de backend: camadas router → controller → service →
  repository, SQLAlchemy 2.0, Pydantic v2.
- **Frontend em JavaScript** — React sobre o
  [`tempest-react-sdk`](https://www.npmjs.com/package/tempest-react-sdk),
  nosso framework de frontend: componentes, hooks e integrações.
- **Visão computacional** — inferência no servidor e no browser com o
  [`ort-vision-sdk`](https://pypi.org/project/ort-vision-sdk/).
- **Decisões e aprendizados** — o que deu certo, o que quebrou em produção e o
  que mudamos por causa disso.

## Quer contribuir?

Todo post é um arquivo Markdown no
[repositório do blog](https://github.com/TempestTecnology/blog). Abra uma issue
com a ideia ou um PR com o rascunho — o passo a passo está no `README.md`.
